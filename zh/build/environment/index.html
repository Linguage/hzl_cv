编辑出版与开发工具

整理技术文档与书籍的排版工程、交互编辑工具和开发环境脚本，解决日常工作中的具体问题。

项目

编辑出版

Edit Engine

当前状态私有源码 · 持续整理

按项目管理技术文档、书籍和双语材料的源文、排版工程与发布成品。

  • 维护XeLaTeX构建规则，以及数学报告、教材、时间线和图文版式等模板。
  • 在发布前检查页面尺寸、字体嵌入、缺字、溢出和未解析引用，再人工确认成品。
  • LaTeX
  • XeLaTeX
  • PDF
  • Templates

交互编辑

Quote Poster Studio

当前状态私有源码 · 早期项目

在浏览器中编辑文字海报，处理图片、文字、画幅和导出。

  • 实现背景图片的上传、粘贴、缩放与拖动，以及文字位置、字体和叠层控制。
  • 提供常用画幅、装饰边框、实时预览和高分辨率图片导出。
  • Next.js
  • TypeScript
  • Canvas
  • Image Export

格式转换

md-press

当前状态公开仓库 · 辅助工具

将Markdown材料转换为适合阅读和印刷的PDF。

  • 处理封面、目录、书签、中文字体、数学公式和代码高亮。
  • 该工具由Linguista Library的PDF流程拆出，作为编辑出版工作中的一个转换环节。
  • TypeScript
  • Node.js
  • Markdown
  • PDF
